Supported formats

Documents

TXT, PDF, and DOCX

Photos

JPG, JPEG, PNG, HEIC, and HEIF

Videos

MP4, MOV, and AVI

Capacity

One file per operation, up to 25 MiB

How to protect a file

  1. Open Hide Text and select File.
  2. Choose an authorized contact, group, or broadcast list.
  3. Select a supported file or choose supported media from the photo library.
  4. Create the hidden file and share it through the app you choose.
  5. The recipient opens Reveal File, then saves or shares the revealed result as appropriate.

Reveal and save

The recipient chooses the hidden file in Hide My Text. The app uses a path-confined temporary area with complete file protection for the revealed file. After successful reveal, the recipient can use available iOS share options to save or send the recovered file.

Choose a supported file

Select one of the listed document, photo, or video formats up to 25 MiB for each protection operation.
