How does Hide My Text work with messaging apps?

It protects supported content locally, then lets the user send the protected output through the separate platform of their choice.

Does Hide My Text require an account, email, or phone number?

No Hide My Text account, email address, or phone number is required to create and use the local vault.

Does Hide My Text run a messaging server?

No Hide My Text messaging server transports users' protected messages or files. The user selects the external platform for delivery.

Does the recipient need Hide My Text?

Yes. The recipient needs the app and the correct trusted contact or approved destination state to reveal protected content intended for them.

How are contacts verified?

Contacts complete an invite and response flow, then compare a safety phrase through a separate trusted method before confirming trust.

How long does an invite last?

Contact and destination invites in build 71 expire after 15 minutes.

Which files are supported?

Documents: TXT, PDF, DOCX. Photos: JPG, JPEG, PNG, HEIC, HEIF. Videos: MP4, MOV, AVI. One file can be protected at a time, up to 25 MiB.

What is the difference between a group and broadcast list?

A private group is a multi-participant protected destination. A broadcast list is controlled by its admin for one-way protected updates to approved members.

How does membership management work?

Administrators can add approved members, remove members, and manage each local group or broadcast-list destination.

How do the recovery phrase and backup work together?

The recovery phrase recreates the local identity and keys. The encrypted backup restores supported contact, group, and broadcast-list records.

What returns after restoring a backup?

Supported contact, group, and broadcast-list records return with contacts and destination members marked Pending, ready for trust verification.

How is recovery controlled?

The user-controlled 12-word recovery phrase is the source for recreating the local identity. Write it down in order and store it securely offline.

How should I store the recovery phrase?

Write it down offline and keep it in a secure location. In build 71, the standard iOS Copy action on the displayed phrase can place it on the system clipboard.

How long does revealed text stay on screen?

Build 71 clears revealed text from its screen after 90 seconds.

Is an iPhone passcode required?

Yes. Hide My Text requires an iPhone device passcode to create and open its encrypted local vault. Face ID or Touch ID is optional. Keep the iPhone passcode enabled to preserve access to the device-only vault key; the recovery phrase and latest encrypted backup provide the recovery path when rebuilding the local vault.

When does the optional App Lock prompt return?

When the additional App Lock prompt is enabled, build 71 allows a 90-second background grace period before locking again. The required iPhone device passcode remains the fallback.
